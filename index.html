        How the comparison is calculated

        Growth = (later value − earlier value) / earlier value × 100. A zero baseline is shown as “New from zero” when the later value is positive, and “N/A” when both values are zero. A missing campaign record or missing value stays unavailable; it is never replaced by zero. Rate comparisons use percentage-point changes, not percentage growth.

        Net value retained = NMV / GMV. Net order retention = Net Orders / Gross Orders. Net item retention = Net Items / Gross Items. AOV, AIV, basket size, and average RTS/TTS are used exactly as reported in the source; their internal definitions are not assumed. Selling SKUs is a source campaign count, not a list of active or offline products.

        Campaign currency and campaign year/start/end dates are not stated in the campaign source. Campaign values are shown in source monetary units without a currency symbol. The separate SKU tabs label accumulated GMV as USD ($); SKU totals are never duration-adjusted. Add confirmed campaign durations to unlock per-day comparison. Only GMV, NMV, orders, and item totals are divided by duration; source averages, ratios, and selling SKU/buyer counts are not normalized. The source monetary fields may use different units, so this dashboard does not infer ROI or promotion efficiency from discount fields.

        Data coverage and source checks

        This is a snapshot, not a live DingTalk connection. Separate labeled SKU tabs are included for five sellers only; they do not replace campaign values. SKU date windows and campaign year remain unconfirmed. An absent seller or SKU row means “not recorded,” not offline or inactive. Campaign CSV replacements leave the embedded SKU snapshot unchanged, so uploaded campaign totals are not assumed to reconcile with it. The page makes no network requests and keeps uploaded CSV data only in memory. Refreshing the page restores the embedded snapshots.

        Data & comparison settings

        Enter confirmed durations if campaign lengths differ. Leave unknown durations blank; a one-day window is never assumed.

        Replace a campaign with CSV

        Export a campaign tab as CSV. It must contain seller_id, seller_name, GMV, NMV, Gross Orders, Net Orders, Gross Items, Net Items, and Selling Skus. Other supported source fields are optional. Required headers may contain blank or dash metric values; those values stay unavailable, never zero. The selected campaign is replaced—not added to existing totals.
